# ODA 기관 로고 (국문·영문 공통)

히어로 CTA 아래 "글로벌 ODA 레퍼런스 & 생태계" 바에서 쓰는 기관 로고입니다.
어두운 배경(국문 보라 / 영문 딥 네이비)에서 읽히도록 **흰색(화이트) 처리**한
공식 아트워크만 두었습니다. 로고는 각 기관의 상표이며, 소개·레퍼런스 표기 목적으로
사용합니다(제휴·보증을 의미하지 않습니다. 캡션도 "레퍼런스 & 생태계"로 표기).
